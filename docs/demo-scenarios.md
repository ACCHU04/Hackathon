# Demo Scenarios

## Demo 1 — Mostly True Article
- **URL**: `https://example.com/article-true`
- **Topic**: Space exploration facts
- **Expected**: All major claims verified as TRUE with NASA/Wikipedia sources cited.
- **Key talking point**: Show claim highlighting and citation links.

## Demo 2 — False / Misleading Article
- **URL**: `https://example.com/article-false`
- **Topic**: Health misinformation
- **Expected**: Claims flagged as FALSE or PARTIALLY_TRUE with authoritative contradicting sources.
- **Key talking point**: Demonstrate the system's ability to catch subtle errors.

## Demo 3 — Conflicting Evidence
- **URL**: `https://example.com/article-conflict`
- **Topic**: Economic statistics (GDP, unemployment)
- **Expected**: Some claims return UNVERIFIABLE or PARTIALLY_TRUE due to differing source data.
- **Key talking point**: Show how the system surfaces conflicting sources without forcing a verdict.
